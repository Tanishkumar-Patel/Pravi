Gujarat Family ID: Beneficiary Management System

Architecture Style: Modular Monolith (Flask Backend + React Frontend)

1. Presentation Layer (Frontend)

Technology: React, Vite, React Router, Axios

  • Citizen Portal: Household registration, member onboarding, and eligibility verification.
  • Admin Dashboard: Application review system, statistics tracking, and duplicate record detection.

2. Business Logic Layer (Backend)

Technology: Python / Flask (Modular Monolith Structure)

  • Authentication: JWT-based role authorization (CITIZEN vs. ADMIN).
  • Eligibility Engine: Dynamic JSON rule evaluation (checking income, age, gender, and occupation).
  • Workflow Management: Automatic benefit generation upon application approval.

3. Database Layer

Technology: Supabase (PostgreSQL)

  • families: Stores core household and income metadata.
  • members: Stores individual dependent profiles linked via foreign keys.
  • schemes: Stores welfare programs and JSON-based criteria.
  • applications & benefits: Tracks lifecycle state and active distributions.
